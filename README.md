# A la mano

Calculadoras del precio real de juegos digitales por país (impuestos, tipo de cambio y recargos).

- `index.html` — inicio
- `argentina.html` — USD × dólar oficial + IVA 21% + Ingresos Brutos por provincia
- `mexico.html` — IVA 16% incluido o conversión desde USD con comisión bancaria
- `styles.css`, `app.js` — estilos y lógica compartida

Sitio estático: se publica en Cloudflare Pages sin comando de build.
Cotizaciones: DolarApi.com. Tasas revisadas el 4 de noviembre de 2026.
